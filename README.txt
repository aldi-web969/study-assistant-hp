STUDY ASSISTANT — VERSI HP

CARA TES PALING MUDAH
1. Upload folder ini ke hosting statis seperti GitHub Pages.
2. Buka index.html dari alamat website tersebut di Chrome HP.
3. Masukkan soal pada kotak.
4. Tekan Analyze.

PENTING
Chrome Android biasa tidak mendukung pemasangan extension Chrome desktop.
Karena itu versi HP ini adalah aplikasi web mobile.

BOOKMARKLET
Versi ini juga menyediakan bookmarklet untuk membaca teks yang terlihat pada halaman:
1. Buka Study Assistant.
2. Tekan "Salin Bookmarklet".
3. Buat bookmark baru di Chrome.
4. Edit URL bookmark dan ganti URL-nya dengan kode javascript:... yang sudah disalin.
5. Saat berada di halaman latihan, buka bookmark tersebut.
6. Teks halaman akan ditampilkan untuk disalin.
7. Kembali ke Study Assistant dan masukkan teks tersebut.
